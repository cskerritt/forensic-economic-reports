Quick Start Guide

Welcome to the Economic Analysis Application. This guide will help you get started quickly.

Recommended Workflow

Follow this step-by-step process for the most efficient workflow.
1

Create a New Evaluee

Start by creating a new evaluee with basic information like name and state.

Create New Evaluee
2

Enter Demographics

Enter demographic information including date of birth, date of injury, gender, and education level.

Pro Tip: Use the "Use Table Values" button to automatically calculate worklife expectancy and years to final separation.

3

Set Worklife Factor

Review and adjust the worklife factor if needed.

4

Create Earnings Scenarios

Add one or more earnings scenarios to model different income possibilities.

5

Add Medical Costs

Enter medical procedures and create cost projections.

6

Add Household Services

Calculate household services losses if applicable.

7

Generate Reports

Create combined reports with all the analysis results.

Using the Wizard

For a guided experience, use the Wizard feature which will walk you through each step of the process.

The wizard automatically saves your progress and validates your inputs at each step.
