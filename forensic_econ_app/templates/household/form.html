About Staged Valuation

This model uses a staged approach to value household services over time. Each stage represents a period with a specific annual value.

How It Works:
  1. Create a scenario with general parameters
  2. Add stages with specific durations and annual values
  3. The system calculates present value based on all factors
Factors Considered:
  • Multiple stages with different durations
  • Area wage adjustments for local market conditions
  • Reduction percentage based on capacity loss
  • Growth rate for future value increases
  • Present value calculation using the discount rate
Tip: Create multiple scenarios to compare different assumptions.
