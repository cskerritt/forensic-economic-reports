About Life Care Plan Module

This module provides comprehensive life care planning capabilities adapted from the MCP Streamlit application. Features include:

  • Evaluee Management: Complete patient profiles
  • Service Planning: Medical, therapy, equipment services
  • Cost Calculations: Present value and inflation adjustments
  • Multiple Scenarios: Conservative, moderate, optimistic
  • Professional Reports: Excel and Word exports
  • Economic Analysis: Comprehensive cost projections
  • Equipment Replacement: Automatic replacement cycles
  • Category Organization: Medical, therapy, medications, etc.
Note: Full functionality requires additional Python packages: pandas, openpyxl, python-docx, matplotlib. This simplified version provides basic evaluee management.
